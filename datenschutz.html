Datenschutzerklärung

Diese Datenschutzerklärung informiert nach dem Schweizer Datenschutzgesetz (DSG) darüber, welche Personendaten Spendly bearbeitet.

Verantwortliche Stelle
Daria Felsberg, Stationsstrasse 18, 8274 Tägerwilen, daria.felsberg@outlook.com

Welche Daten gespeichert werden

  • Konto: Benutzername, E-Mail-Adresse und das Passwort als gesalzener bcrypt-Hash. Das Passwort selbst wird nie gespeichert.
  • Anmeldung: ein Sitzungs-Token, damit du angemeldet bleibst.
  • Finanzdaten: Einträge, Konten und Kontostände, Monatsbudget, wiederkehrende Buchungen und eigene Kategorien, so wie du sie erfasst.

Wo die Daten gespeichert werden

  • Server: Konto und Finanzdaten liegen in einer Datenbank bei Supabase (Supabase Inc., USA; Rechenzentrum in der EU, Frankfurt). Supabase bearbeitet die Daten als Auftragsbearbeiter nur zur Bereitstellung der App.
  • Hosting: Die App-Dateien von app.spendly.ch werden über Vercel (Vercel Inc., USA) ausgeliefert. Dabei fallen technische Zugriffsdaten wie die IP-Adresse an.
  • Dein Gerät: eine Kopie im lokalen Speicher deines Browsers (localStorage), damit die App schnell lädt und auch offline funktioniert.

Zweck
Die Daten werden ausschliesslich verwendet, um dir die App bereitzustellen, also um deine Finanzübersicht zu speichern und auf deinen Geräten anzuzeigen. Es gibt keine Werbung, kein Tracking und keine Weitergabe an Dritte zu Werbe- oder Analysezwecken.

E-Mails
Deine E-Mail-Adresse wird nur für kontobezogene Nachrichten verwendet, z. B. zum Zurücksetzen des Passworts. Diese E-Mails werden über den Mailserver von Infomaniak (Infomaniak Network SA, Genf, Serverstandort Schweiz) verschickt.

Google Fonts
Die Schriftarten werden von Google Fonts geladen. Dabei wird deine IP-Adresse an Google übermittelt, auch an Server ausserhalb der Schweiz.

jsDelivr
Die Programmbibliothek für die Anmeldung (supabase-js) wird über das Content Delivery Network jsDelivr geladen. Dabei wird deine IP-Adresse an dessen Server übermittelt, auch ausserhalb der Schweiz.

Aufbewahrung und Löschung
Die Daten bleiben gespeichert, solange dein Konto besteht. Du kannst dein Konto mit allen Daten jederzeit selbst in den Einstellungen löschen, oder per E-Mail darum bitten. Die lokale Kopie auf dem Gerät wird dabei ebenfalls entfernt. Auf anderen Geräten kannst du sie über die Browser-Einstellungen löschen.

Deine Rechte
Du hast das Recht auf Auskunft über deine Daten, auf Berichtigung und auf Löschung. Wende dich dafür an die oben genannte E-Mail-Adresse.
